Token 计算器 v1.0.0
==================

一个离线、精确的 token 计数器与 API 成本估算器。


【怎么用】
----------
双击 Token计算器.html 即可，不需要安装任何东西，不需要联网。

把文本粘贴进去，或者直接把 .txt / .md / 代码文件拖进输入框，
下面立刻显示 token 数、字符数、成本估算。

界面上的 token 会按切分结果着色，方便看清模型是怎么切的。


【它是精确的，不是估算】
------------------------
内置六套真实的官方词表，分词结果与官方工具逐 token 一致：

    DeepSeek        127,997   覆盖 DeepSeek-V3 / V3.2 / V4 系列
    Qwen            151,643   覆盖 Qwen2.5 / Qwen3
    Qwen3.8         248,044   覆盖 Qwen3.8 系列
    GLM             154,820   覆盖 GLM-4.6 / GLM-5 系列
    OpenAI o200k    199,998   覆盖 GPT-4o / GPT-5 系列
    OpenAI cl100k   100,256   覆盖 GPT-4 / GPT-3.5

已用 7400 多条语料（中英日韩、emoji、组合字符、代码、JSON、各种空白换行）
与官方库逐条比对：7398/7398 完全一致。


【注意：这四家是近似值】
------------------------
以下厂商没有公开可用于本项目的词表，程序用体积相近的词表近似，
表格里会显示黄色的 ≈ 标记。这些数字可能与真实值有偏差，请仅作粗略参考：

    Anthropic（Claude）  -> 用 OpenAI cl100k 近似
    Google（Gemini）     -> 用 OpenAI o200k 近似
    月之暗面（Kimi）      -> 用 DeepSeek 词表近似
    字节豆包（Doubao）    -> 用 OpenAI cl100k 近似


【关于价格】
------------
价格整理于 2026-10，以各厂商官方定价页为主，并用 LiteLLM 公开价目表交叉核对。

厂商随时会调价、改名、下线模型，请以官网为准。界面上的价格都可以直接改，
改完成本会立刻重算；也可以自己添加模型。

DeepSeek 有「空闲时段半价」，勾选后会自动按半价计算。

人民币与美元不会混着算：豆包是人民币计价，会明确标出来，不会静默换算。


【关于换行符（一个容易踩的坑）】
--------------------------------
浏览器的输入框会把 \r\n 和 \r 都转成 \n，这会改变 token 数。

如果你拖入一个含 CR 的文件，程序会单独提示按文件原始字节统计的真实 token 数，
不会悄悄给你一个偏差值。


【隐私】
--------
全部计算都在你的浏览器本地完成，文本不会发送到网络。
你可以断网使用，也可以把这个 HTML 拷给别人。
