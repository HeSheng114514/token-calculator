说明

关于精确性：本工具内置的是各厂商真实的 BPE 词表（DeepSeek、Qwen、 Qwen3.8、GLM、OpenAI o200k / cl100k），按官方预切分正则 + 字节级 BPE 合并， 结果与官方分词器逐 token 一致（已用 7400+ 条中英日韩、emoji、组合字符、 代码、空白等语料与官方库比对通过）。

关于换行符：输入框（浏览器 textarea）会把 \r\n 与 \r 统一成 \n，这会让 token 数略有差异。 拖入含 CR 的文件时页面会单独提示原始字节下的真实计数。

关于价格：价格整理于 2026-10，以厂商官方定价页为主、LiteLLM 公开价目表 交叉核对；厂商随时调价下线，请以官网为准。存在缓存计价的模型会单独列出 「命中缓存」一行。DeepSeek 有空闲时段半价，页面上可切换。

关于隐私：全部计算都在您的浏览器本地完成，文本不会发送到网络。
